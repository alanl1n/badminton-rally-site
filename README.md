# badminton-rally-site

`回合剪辑` iOS App 的两份对外材料，公开托管用：

- `index.html` — 隐私政策页（App Store Connect 必填的「隐私政策网址」）
- `sample_150s_720p.mp4` — 给 App Store 审核员的示例素材，见 Releases

隐私政策网址：https://alanl1n.github.io/badminton-rally-site/

示例素材直链：https://github.com/alanl1n/badminton-rally-site/releases/download/v1/sample_150s_720p.mp4

这个仓库只放上面两样东西。App 源码和研究数据在私有仓库，不在这里。
